
Retrieval-Augmented Generation (RAG) is an architectural pattern that optimizes the output of a Large Language Model (LLM).
It achieves this by referencing an authoritative knowledge base outside of its training data sources before generating a response.
LLMs are trained on vast volumes of data and use billions of parameters to generate original text for tasks like answering questions or translating languages.
However, standard LLM responses can be outdated, inaccurate, or generic. RAG addresses this by retrieving relevant documents from an external vector database.
The system then combines these retrieved document snippets with the user's original prompt, giving the LLM up-to-date context to ensure factual, accurate answers.
